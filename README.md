# Workout Manager

A small Java / JavaFX desktop app to build a weekly training program and analyze it. Student project.

## Features

- Create a program or load a saved one (max 7 sessions, i.e. one training week)
- Add sessions, pick exercises from a catalog (~80 movements: powerlifting, bodybuilding, calisthenics) and log each round (reps x weight)
- Stats per session and per program:
  - total tonnage
  - estimated calories
  - sets per muscle group
  - sets per exercise
- Save / load programs as JSON files

## Quick start

**Requirements**

- JDK 25 (the version used for development)
- [JavaFX SDK 26](https://gluonhq.com/products/javafx/) (extract it anywhere)
- Gson is already included in `lib/`

**Option A: Eclipse**

1. Import the project (File > Import > Existing Projects, or clone the repo and create a Java project from it)
2. Add `lib/gson-2.14.0.jar` and the JavaFX SDK jars to the Build Path
3. Run `WorkoutManagerApp` with these VM arguments:
   ```
   --module-path "C:\path\to\javafx-sdk\lib" --add-modules javafx.controls
   ```

**Option B: command line** (from the project root, so `exercises.csv` is found)

```
javac --module-path "C:\path\to\javafx-sdk\lib" --add-modules javafx.controls -cp lib\gson-2.14.0.jar -d bin src\WorkoutManager\*.java
java --module-path "C:\path\to\javafx-sdk\lib" --add-modules javafx.controls -cp "bin;lib\gson-2.14.0.jar" WorkoutManager.WorkoutManagerApp
```

On Linux / macOS, replace `;` with `:` and `\` with `/`.

## Project structure

```
src/WorkoutManager/   Java sources
lib/                  Gson jar
exercises.csv         Exercise catalog (name,muscleGroup,met)
```

Model: `Program` > `Session` > `ExerciseDone` > `Round`, where each `ExerciseDone` references an `ExerciseReference` from the catalog (composition, no inheritance).

## About the exercise catalog

`exercises.csv` was **generated by an AI**, and the **MET coefficients are its estimates**: they are consistent relative to each other (a heavy squat is higher than a bicep curl) but are **not taken from a validated scientific table**. Calories are computed as `average MET of the session x body weight x duration`, so they are only **indicative**.

You can add your own exercises by appending lines with the same format: `name,muscleGroup,met` (no comma in the name, decimal point for the MET).

## Known limitations

- Body weight is asked at every launch (it is not saved in the JSON, so calories stay up to date)
- Existing rounds cannot be edited afterwards; only the last round can be removed while adding an exercise
- Saved programs are written next to the app, as `<program name>.json`
